Анализ данных

Визуализация графиков и статистических зависимостей

Категориальные распределения

Распределение ванных комнат
Показывает количество объектов с разным числом ванных комнат в датасете.
Распределение типов зданий
Визуализация различных типов зданий и их частоты в данных.
Распределение состояний
Анализ состояния объектов недвижимости в выборке.
Распределение по районам
Географическое распределение объектов по различным районам.
Распределение типов отопления
Частота различных типов систем отопления в объектах.
Распределение ремонта
Показывает долю объектов с различным состоянием ремонта.
Распределение комнат
Статистика количества комнат в объектах недвижимости.
Распределение техпаспортов
Наличие технических паспортов у объектов в датасете.

Числовые распределения

Распределение площади (м²)
Гистограмма распределения площади объектов недвижимости.
Boxplot площади (м²)
Диаграмма размаха показывает медиану, квартили и выбросы для площади.
Распределение цен
Гистограмма распределения цен на объекты недвижимости.
Boxplot цен
Визуализация статистики цен: медиана, квартили и аномальные значения.

Корреляционный анализ

Тепловая карта корреляций
Матрица корреляций между числовыми признаками. Красный цвет - сильная положительная связь, синий - отрицательная.
Корреляция цены с признаками
Показывает силу связи между ценой и другими числовыми параметрами объектов.

Анализ зависимостей

Цена vs Площадь
Зависимость цены от площади объекта. Показывает, как площадь влияет на стоимость.
Цена vs Этаж
Влияние этажа расположения на цену недвижимости.
Цена vs Количество комнат
Связь между количеством комнат и ценой объекта.
Средняя цена по типу здания
Сравнение средних цен для разных типов зданий.
Средняя цена по району
Географический анализ: средние цены в различных районах.
Средняя цена по ремонту
Влияние состояния ремонта на среднюю стоимость объектов.
Средняя цена по количеству комнат
Средние цены в зависимости от количества комнат в объекте.
